# Stock image sources

Sites By Leon stores its example photography locally as optimized WebP files. The originals were selected from the free Unsplash catalog; no Unsplash+ images are included and no image contains a watermark.

Unsplash permits free commercial and non-commercial use without required attribution: <https://unsplash.com/license>.
